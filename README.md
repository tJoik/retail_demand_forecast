# Прогнозирование продаж хозяйственного магазина

Пайплайн прогнозирования недельных, месячных и квартальных продаж для розничного магазина. От выгрузки из 1С до FastAPI-сервиса с UI, откуда можно получить прогноз в разрезе категорий и выгрузить заявку на закупку в Excel.

## Стек

- **ML**: XGBoost, scikit-learn Pipeline, TargetEncoder, TimeSeriesSplit, GridSearchCV.
- **Метрики**: WAPE, R².
- **Сервис**: FastAPI + Jinja2, экспорт в Excel через openpyxl.
- **Данные**: 1С COM-коннектор, Open-Meteo API, holidays.

| Квартал | 1.38 | 3.487 | 0.37 | 26 116 |

## Как запустить

### 1. Окружение

Разработка велась на Python 3.13.5.

```bash
pip install -r requirements.txt
```

При необходимости выгрузить данные из 1С, необходимо раскомментировать `pywin32` в `requirements.txt`. Сработает только в Windows.

### 2. Данные

Для полного пайплайна и корректного функционирования сервиса нужен `features/features_one_week.csv`. Его собирает [features_import_one_week.ipynb](features_import_one_week.ipynb) из базы 1С (1c_files/) в корне (сработает при наличии 1С:Предприятие 8.3 на ПК). Ни база 1С (1c_files/) ни файл `features/features_one_week.csv` в репозиторий не коммитятся (данные принадлежат компании и не публикуются, доступны по запросу).

В `features_import_one_week.ipynb` логин и пароль к 1С заменены на заглушки ("***"). Перед запуском необходимо указать логин и пароль, которые доступны по запросу.

### 3. Обучение

Требуется `features/features_one_week.csv` из шага 2.
Чтобы получить обученную модель необходимо запустить данные ноутбуки:
- [make_one_week_model.ipynb](make_one_week_model.ipynb)
- [make_one_month_model.ipynb](make_one_month_model.ipynb)
- [make_3_month_model.ipynb](make_3_month_model.ipynb)

Каждый из ноутбуков сохраняет обученную модель в `models/`.

### 4. Сервис
Для его запуска необходимо ввести следующие команды в терминал:
```bash
python service/precompute.py     # пересчёт матриц признаков для ближайшего прогнозного периода
python service/run.py            # запуск uvicorn
```

Сервис запустится локально: `http://127.0.0.1:8000`

## Пайплайн подготовки данных

1. 1С COM-коннектор: в результате запросов к 1C получаем: продажи по неделям, движения приходов, история цен, остатки на начало недели.
2. Merge: продаж, цен, дат последнего поступления, погоды и праздников
3. Признаки в ноутбуках:
   - TF-IDF по наименованию товара (tfidf_mean);
   - добавление бренда из справочника поставщиков;
   - оконные статистики продаж по окнам [2, 4, 8, 12] недель и те же окна со сдвигом на неделю - 56 признаков.

Для месячной/квартальной моделей всё реализовано аналогично, за исключением того, что они агрегируются из недель в месяцы и кварталы, а также квартал имеет некоторые дополнительные признаки.

## Выбор параметров модели XGboost

GridSearchCV по сетке `n_estimators: [300, 600], max_depth: [4, 6]` с TimeSeriesSplit-3, scoring на CV - WAPE. Лучший результат CV:

| Горизонт | n_estimators | max_depth | CV-WAPE |
|---|---|---|---|
| Неделя | 600 | 6 | 0.732 |
| Месяц | 300 | 4 | 0.701 |
| Квартал | 300 | 4 | 0.669 |
